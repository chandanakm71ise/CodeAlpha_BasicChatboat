# Basic Chatbot

## About
A simple rule-based chatbot developed using Python. It responds to basic user messages with predefined replies.

## Features
- Responds to greetings
- Responds to "how are you"
- Responds to "bye"
- Simple console input and output
- Easy to use

## Technologies Used
- Python
- If-elif conditions
- Functions
- While loop
- Input and output

## How to Run
1. Download or clone this repository.
2. Open `chatbot.py` in Python or VS Code.
3. Run the program.
4. Enter a message and interact with the chatbot.
